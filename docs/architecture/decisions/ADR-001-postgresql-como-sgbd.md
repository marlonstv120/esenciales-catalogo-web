# ADR-001: PostgreSQL como SGBD

## Estado

Accepted

## Contexto

El proyecto requiere definir el sistema gestor de base de datos. El curso establece tecnologías web, pero no determina este componente.

## Decisión

Utilizar PostgreSQL como sistema gestor de base de datos del proyecto.

## Motivos

Decisión confirmada por el equipo del proyecto.

## Alternativas consideradas

No documentadas todavía.

## Consecuencias

La futura arquitectura e implementación deberán ser compatibles con PostgreSQL. No se deriva la selección de ORM, librerías, estructura, autenticación, hosting ni otros componentes.
