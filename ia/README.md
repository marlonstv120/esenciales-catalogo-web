# Registro de uso de IA

Esta carpeta conserva la evidencia academica del uso de inteligencia artificial en el proyecto. No reemplaza la documentacion tecnica ni la toma de decisiones del equipo.

Cada uso relevante se registra en [`registro-uso-ia.md`](registro-uso-ia.md) con el objetivo, la herramienta, el aporte recibido, la revision humana y el resultado incorporado. No se deben incluir secretos, datos personales, conversaciones completas innecesarias ni contenido que no haya sido revisado por el equipo.

La carpeta [`.ai/`](../.ai/) tiene otro proposito: facilita la continuidad operativa entre agentes y no constituye evidencia academica.
