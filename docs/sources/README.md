# Fuentes base

Esta carpeta conserva documentos originales del proyecto y del curso, además de insumos externos identificados expresamente como análisis. Los agentes no deben modificar automáticamente su contenido.

Los documentos oficiales del curso y las instrucciones directas del profesor tienen prioridad. El contexto confirmado del proyecto respalda las decisiones internas registradas por el equipo.

Un análisis externo, como `ANALISIS_PROPUESTA_ESENCIALES_CLAUDE.md`, es material de contraste y no se convierte automáticamente en fuente de requisitos, evidencia académica o resultados. Sus propuestas requieren aceptación expresa del equipo y, cuando corresponda, validación del profesor o del negocio.

Los documentos derivados deben resumir solo lo necesario, enlazar las fuentes cuando corresponda y distinguir hechos, decisiones, propuestas y pendientes.
