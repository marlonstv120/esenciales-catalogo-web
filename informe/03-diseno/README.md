# Diseno

- [`wireframe/`](wireframe/): archivos PNG, uno por pantalla o estado relevante.
- [`mockup/`](mockup/): archivos PNG por pantalla y enlace al prototipo de Figma.

Use nombres en minusculas, sin tildes ni espacios, por ejemplo `catalogo-publico.png`. Los archivos HTML utilizados para previsualizaciones locales no son entregables y estan excluidos de Git.

La [guia de wireframes](../../docs/project/wireframe-guide.md) define las pantallas, estados y criterios vigentes. No agregue imagenes de ejemplo como si fueran evidencias reales.
