# Decisiones arquitectónicas

Los ADR se crean para decisiones técnicas relevantes y confirmadas, con el formato `ADR-001-titulo-decision.md`.

Cada ADR incluirá: Estado, Contexto, Decisión, Motivos, Alternativas consideradas y Consecuencias.

Estados permitidos: `Proposed`, `Accepted`, `Superseded` y `Deprecated`.
