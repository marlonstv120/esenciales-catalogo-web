# Contexto del curso

## Resumen operativo

**Confirmado por fuentes oficiales:** el curso es una opción de grado de 64 horas, con metodología de aprendizaje basado en proyectos y un producto integrador. El brochure describe como producto final una aplicación web Full Stack desplegada, con control de versiones, informe académico y sustentación.

El documento metodológico establece evaluación por avances, documento y sustentación; grupos de máximo tres integrantes; informe entre 16 y 25 páginas; mínimo diez referencias verificables; y sustentación máxima de 15 minutos.

La plantilla vigente define una estructura inicial y requisitos formales para el informe. Las indicaciones posteriores y explícitas del profesor tienen prioridad.
