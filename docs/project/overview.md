# Visión general

## Qué es Esenciales

Esenciales es un emprendimiento real que comercializa lociones, splash, cremas, humidificadores y otros productos. Fuente: [CONTEXTO_PROYECTO_ESENCIALES.md](../sources/CONTEXTO_PROYECTO_ESENCIALES.md).

## Sistema en desarrollo

Se desarrollará una aplicación web para la gestión y publicación del catálogo de productos de Esenciales.

## Situación y propósito

**Confirmado:** el proyecto aborda la necesidad de centralizar la administración y consulta del catálogo, ante el manejo previo de información mediante Excel y el envío de numerosas fotografías por WhatsApp.

**Preliminar:** la formulación del problema y la solución propuesta deben ajustarse cuando existan indicaciones metodológicas o validaciones adicionales.

## Estado

La implementación de la aplicación aún no inicia.

**Tecnologías exigidas por el curso:** HTML5, CSS3, JavaScript, Node.js, Express y Git/GitHub.

**Decisión técnica confirmada:** PostgreSQL será el sistema gestor de base de datos del proyecto. Los demás componentes de la arquitectura siguen pendientes de definición.
