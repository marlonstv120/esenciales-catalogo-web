# Alcance

Todo cambio significativo de alcance debe registrarse aquí y conservar trazabilidad en el historial.

## Confirmado

- El proyecto se enfoca inicialmente en Esenciales como caso real.
- Se prioriza un MVP Full Stack completo, funcional, desplegado y sustentable durante el curso.

## Preliminar

- Gestión y publicación del catálogo de Esenciales.
- Administración de categorías, productos, precios, imágenes e inventario o disponibilidad.
- Catálogo público, carrito, generación y registro de solicitudes de cotización y preparación de mensaje para WhatsApp.
- Autenticación para quienes administren el sistema.

Estas funcionalidades candidatas no son requisitos definitivos. Fuente: [CONTEXTO_PROYECTO_ESENCIALES.md](../sources/CONTEXTO_PROYECTO_ESENCIALES.md).

## Pendiente de validar

- Requisitos definitivos, permisos, manejo de inventario y detalles del flujo de cotización.
- Alcance validado con el profesor y el caso real.

## Fuera del MVP

- Pasarela de pagos, facturación electrónica, contabilidad, deudas o abonos avanzados, suscripciones y planes comerciales.
- Múltiples emprendimientos o catálogos independientes.
- Integración compleja con la API de WhatsApp.
- Funcionalidades avanzadas equivalentes a plataformas comerciales existentes.

## Evolución futura

Una plataforma para que múltiples emprendimientos creen y administren sus propios catálogos. No forma parte del MVP actual.
