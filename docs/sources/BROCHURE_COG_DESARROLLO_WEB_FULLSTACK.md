## 1. Presentación del curso
En un mundo digital donde las aplicaciones web son el motor de la innovación, el Diplomado en Desarrollo Web Full Stack prepara a los estudiantes para diseñar, construir y desplegar soluciones completas, desde el frontend hasta el backend. El programa integra HTML5, CSS3, JavaScript, Node.js y prácticas de despliegue, ofreciendo una formación integral que responde a las demandas actuales del sector tecnológico y empresarial.

---

## 2. Justificación
El diplomado responde a la necesidad de formar profesionales capaces de crear aplicaciones web modernas, seguras y escalables. La industria requiere desarrolladores con competencias en frontend, backend y control de versiones, que puedan integrarse en equipos ágiles y aportar soluciones innovadoras. Este programa fortalece la empleabilidad y la competitividad, articulándose con proyectos de investigación aplicada y con las tendencias de transformación digital.

---

## 3. Articulación con las Líneas de Investigación UTAP
Este curso se articula de manera directa con las siguientes líneas:
* **A. Transformación y Fortalecimiento Social en CTI:** Uso de datos e IA para la mejora de procesos organizacionales con impacto social.
* **B. Desarrollo Humano, Comunicación e Innovación (capacidades técnicas en CTeI):** Fortalecimiento de competencias técnicas, analíticas y digitales en estudiantes.
* **C. Innovaciones Sociales y Productivas en CTI:** Aplicación de analítica e IA para resolver problemas empresariales y sociales reales.

---

## 4. Objetivos

### 4.1. Objetivo General
Desarrollar competencias técnicas y prácticas en desarrollo web Full Stack, integrando frontend, backend, control de versiones y despliegue, para diseñar aplicaciones completas y funcionales que respondan a necesidades reales del entorno tecnológico y empresarial.

### 4.2. Objetivos Específicos
* Comprender los fundamentos de HTML5 y CSS3 para construir interfaces web responsivas.
* Aplicar JavaScript en la programación de lógica y dinámicas interactivas.
* Utilizar Git y GitHub para el control de versiones y trabajo colaborativo.
* Implementar servicios backend con Node.js y Express.
* Integrar frontend y backend en proyectos Full Stack.
* Desplegar aplicaciones en entornos de producción.

---

## 5. Resultados de Aprendizaje
Al finalizar el curso, el estudiante será capaz de:
* Diseñar interfaces web modernas y responsivas.
* Programar funcionalidades dinámicas con JavaScript.
* Gestionar proyectos con Git y GitHub.
* Construir APIs y servicios backend con Node.js.
* Integrar aplicaciones Full Stack y desplegarlas en la nube.
* Sustentar un proyecto aplicado de desarrollo web.

---

## 6. Metodología
La metodología combina clases teórico-prácticas, actividades y laboratorios aplicados. Se trabaja bajo la estrategia de **Aprendizaje Basado en Proyectos (ABP)**, donde los estudiantes desarrollan una aplicación web completa como producto integrador. El acompañamiento tutorial garantiza la consolidación del proyecto en cada una de las fases; el estudiante realiza entregas cada que finalice un módulo con el objetivo de ver un avance hacia la construcción de su sustentación final.

## Módulos del Curso

### Módulo 1. Proyectos (4 horas)
* Introducción al curso.
* Explicación de la metodología ABP.
* Definición de proyectos aplicados.
* Lineamientos para el informe técnico y sustentación del proyecto.

### Módulo 2. Introducción HTML5 (4 horas)
* Fundamentos de estructura y semántica web.
* Introducción al Desarrollo Web.
* Concepto de HTML5 y estructura de una página.
* Etiquetas comunes (Títulos, párrafos, listas y enlaces).
* Incorporación de imágenes, videos y embebidos (iframes, embed, video, img, figure).
* Formulario en HTML y sus elementos.
* Semántica HTML5.

### Módulo 3. Estilos con CSS3 (8 horas)
* Estilos, diseño responsivo y animaciones.
* Introducción a CSS, selectores y propiedades CSS.
* Modelo de Caja (Box Model).
* Estilización de textos, fuentes, colores y fondos.
* Layout con FlexBox y Grid.
* Diseño responsivo y Media Queries.
* Transiciones y animaciones.

### Módulo 4. Programación con JavaScript (12 horas)
* Programación dinámica y asincronía ES6.
* Lógica de programación e introducción a JavaScript.
* Variables, tipos de datos, operadores.
* Estructuras de control (Condicionales y bucles).
* Funciones y alcance (Scope).
* JSON y Fetch API.
* Programación Asíncrona (Promesas, Callbacks).
* ES6 (ECMAScript 6: let, const, arrow functions, template strings).

### Módulo 5. Control de Versiones con Git (12 horas)
* Control de versiones y trabajo colaborativo.
* Introducción al control de versiones.
* Git (Repositorios, commits, branches).
* Trabajando con Git (push, pull, merge).
* Repositorios remotos (GitHub, pull request, issues).

### Módulo 6. Backend con Node.js (16 horas)
* Backend con Express y conexión a base de datos.
* Introducción a la línea de comandos.
* Ejecución de Scripts con NodeJS.
* Instalación de librerías y paquetes con NPM.
* Creación de API con Express.
* Lectura y guardado de información con Express y Bases de datos.

### Módulo 7. Integración Fullstack (8 horas)
* Intercambio de datos, seguridad y despliegue.
* Intercambio de datos entre frontend y backend.
* Prácticas de desarrollo Web Full Stack (SEO, Rendimiento y Seguridad).
* Despliegue a producción (Netlify, Vercel o Fly.io).

---

## 7. Evaluación del Curso
* Actividades prácticas y ejercicios aplicados al proyecto.
* Avances del proyecto integrador en cada módulo.
* Informe técnico del proyecto.
* Sustentación académica del proyecto final.

---

## 8. Producto Final del Curso
Una aplicación web Full Stack desplegada en producción, que integre:
* Frontend con HTML5, CSS3 y JavaScript.
* Backend con Node.js y Express.
* Control de versiones con Git/GitHub.
* Despliegue en la nube.
* Informe académico y sustentación.
