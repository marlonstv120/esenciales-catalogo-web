# Flujo de trabajo

- Revisar documentación y código relacionados antes de cambiar algo.
- Mantener los cambios simples, comprensibles y compatibles con el curso.
- Actualizar documentación únicamente cuando el cambio la afecte.
- Revisar y comprender las contribuciones generadas con IA; probarlas antes de considerarlas correctas.
- No incluir secretos en el repositorio.
- Las reglas concretas de Git, revisión y trabajo colaborativo se documentarán cuando sean acordadas.
