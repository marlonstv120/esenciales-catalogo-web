# Identidad visual de ESENCIALES

**Estado:** referencia visual derivada del [logo oficial](../sources/logo_esenciales.jpg). Sirve de guía para el diseño del sitio y no modifica el alcance funcional del MVP.

## Elementos confirmados

- **Nombre de marca:** Esenciales.
- **Eslogan:** `TU AROMA, SIEMPRE CONTIGO.`
- **Isotipo:** una botella de perfume estilizada, construida con líneas curvas que forman tres secciones similares a pétalos u hojas, y un atomizador geométrico en la parte superior.
- **Logotipo:** el isotipo se ubica sobre el nombre; una línea fina separa el nombre del eslogan.
- **Composición:** centrada, simétrica y con amplio espacio negativo.
- **Estilo:** minimalista, elegante y asociado a la perfumería de lujo.
- **Tratamiento visual:** fondo negro liso y trazos/texto con acabado dorado brillante o metálico.

## Paleta de referencia

Los siguientes valores reproducen de forma aproximada el contraste observado en el logo. Deben validarse con el propietario antes de declararlos colores de marca definitivos.

| Uso sugerido | Color | Valor de referencia |
| --- | --- | --- |
| Fondo principal | Negro | `#000000` |
| Color de marca principal | Dorado | `#D4AF37` |
| Brillo o acento dorado | Dorado claro | `#FFDF73` |
| Texto sobre fondo claro | Negro | `#000000` |

El dorado degradado se reserva para el logo y detalles destacados. Los controles, mensajes y estados del sistema deben conservar contraste suficiente y no comunicar su significado solo mediante color.

## Tipografía y jerarquía

- El nombre **Esenciales** utiliza una tipografía manuscrita o cursiva, fluida y de alto protagonismo.
- El eslogan utiliza una tipografía sans-serif, en mayúsculas y con lectura clara.
- Para textos de interfaz, catálogos, precios, formularios y tablas se debe preferir una sans-serif legible; no se debe usar la tipografía cursiva para contenido extenso ni controles.
- La fuente exacta del logo no está identificada y no debe sustituirse o recrearse como texto sin validación. Cuando sea posible, se debe mostrar el archivo de logo proporcionado.

## Orientación para la interfaz

- El sitio público puede usar el negro como base visual, dorado para llamados a la acción y acentos, y superficies neutras que mantengan una lectura cómoda de productos e imágenes.
- La página de inicio debe dar protagonismo al logo, al eslogan y a las fotografías de productos, sin recargarla con decoraciones que compitan con la marca.
- Las tarjetas, botones y separadores pueden retomar líneas finas, curvas suaves y espacio generoso, coherentes con el isotipo.
- La administración debe diferenciarse visualmente del sitio público, pero puede conservar la identidad mediante el logo y acentos dorados discretos.
- La accesibilidad prevalece sobre el estilo: texto, disponibilidad, errores y estados de solicitudes deben expresarse también con etiquetas o mensajes claros.

- Tipografías licenciadas o alternativas aprobadas para la interfaz.
