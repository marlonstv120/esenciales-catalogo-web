Planteamiento

Pregunta problema

¿Cómo desarrollar una aplicación web full stack que permita centralizar la gestión, publicación y consulta del catálogo de productos, precios y disponibilidad del emprendimiento Esenciales?

La pregunta orienta el diagnóstico, el desarrollo y la validación

3

Dirección del proyecto

UTAP

Objetivos

Objetivo general

Desarrollar una aplicación web full stack para centralizar la gestión, publicación y consulta del catálogo de productos, precios y disponibilidad de Esenciales.

  1. 1 Diagnosticar el proceso actual y sus dificultades de organización y consulta.
  2. 2 Desarrollar la solución con gestión administrativa, catálogo público y solicitudes de compra.
  3. 3 Validar mediante pruebas funcionales y despliegue el cumplimiento de los requisitos.

Tres etapas: diagnóstico, desarrollo y validación

4

Solución propuesta

UTAP

Alcance del producto mínimo viable

01–02

Acceso administrativo y estructura del catálogo.

03–04

Productos, presentaciones, precios, imágenes e inventario.

05–06

Catálogo público, búsqueda, filtros y navegación.

07–08

Carrito, solicitudes de compra y gestión de sus estados.

Límite: el cliente no necesita una cuenta, no se procesan pagos y una solicitud no equivale a una venta. La conversación comercial puede continuar voluntariamente por WhatsApp.

MVP exclusivo para el emprendimiento Esenciales

Gestión de información de producto y catálogo digital Aplicación web full stack y modelo cliente-servidor Base de datos relacional e integridad de los datos Publicación de contenido multimedia Gestión de inventario y disponibilidad comercial
