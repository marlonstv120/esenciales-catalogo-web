# Fuentes base

Esta carpeta contiene las fuentes de verdad originales del proyecto y del curso. Los agentes no deben modificarlas automáticamente.

Los documentos derivados deben consultarlas, resumir solo lo necesario y enlazarlas cuando corresponda. Se pueden agregar nuevas fuentes a medida que avance el curso. Las instrucciones explícitas y más recientes del profesor tienen prioridad cuando apliquen.
